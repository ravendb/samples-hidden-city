RavenDB features used

  • Documents — Route data, conversation sessions, airport metadata — all in one cluster
  • Vector Search — Semantic route similarity — search by country instead of a specific airport (e.g. "England" surfaces LHR, LGW, MAN) or by vibe ("something like LHR but cheaper") — no separate vector DB
  • Subscriptions — Price-drop push alerts to the agent worker — zero polling loops
  • Attachments — Passport scans, bag photos, preference sheets — saved to the user profile and persisted in the database
  • Document Expiration — Price fields auto-expire after 20 min via @expires metadata — no manual TTL management
  • Kubernetes Operator — RavenDBCluster CRD handles bootstrapping, TLS, rolling upgrades with Raft quorum gates
